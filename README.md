# jogosdigitaisprojeto - Projeto IOT

Jogo Referencia: Geometry Dash
Ideia: utilizar a movimentação da cabeça para controlar o mouse, movimentado o personagem em um jogo como geometry dash.
Tipo de Acessibilidade / Doença: Parkinson nos olhos
Tipo de Acessibilidade / Doença: Paralisia cerebral infatil

fases: Cada fase tem um nível de movimentação de acordo com o que for coletado no acelerômetro; se for uma movimentação mais rápida, a fase vai ficando mais complicada
